# Telegram Helpdesk Bot

Telegram bot for internal IT support requests.

## Features

- Multi-step conversation for creating support tickets
- Admin reply functionality (command & reply to message)
- PostgreSQL support (planned)
- Queue system with Bull/Redis (planned)

## Tech Stack

- Node.js
- Telegraf (Telegram Bot Framework)
- PostgreSQL (planned)
- Bull + Redis (planned)
